# organismal-field-data
Practice repository for Duke BIO590S course
## Data Dictionary (metadata)
* `specimen_id`: Unique identifier for each collected/observed
organism.
* `species_binomial`: Genus and specific epithet (Latin name).
* `collection_date`: Date of collection formatted as YYYY-MM-DD.
* `latitude` / `longitude`: Geographic coordinates in decimal
degrees.
* `hindlimb_length_mm`: Length of the right hindlimb measured in
millimeters (`NA` indicates missing data).
